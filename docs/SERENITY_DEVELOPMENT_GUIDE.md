# Development guide

Prerequisites: Node.js 22+, npm, PHP 8.3+, Composer, Flutter with Dart 3.7+, and Chrome. Android SDK is needed for APK builds. From repository root, `./infrastructure/development/api.ps1` initializes a fresh local Laravel API and starts it. Alternatively, from `services/api`, copy `.env.example` to `.env`, create an empty `database/database.sqlite`, run `composer install`, `php artisan key:generate`, `php artisan migrate --seed`, then `php artisan serve`. Seeded accounts and therapists are synthetic development data. Run `php artisan test` and `php artisan route:list --path=api`. Start Reverb separately with `php artisan reverb:start` and set `BROADCAST_CONNECTION=reverb` when testing realtime.

From `apps/mobile`, run `flutter pub get`, `flutter analyze`, `flutter test`. For Android emulator: `flutter run -d android --dart-define=API_BASE_URL=http://10.0.2.2:8000/api/v1`. Build APK with `flutter build apk --release --dart-define=API_BASE_URL=https://your-staging-api/api/v1`.

For the React browser trial at `http://127.0.0.1:3000`, run `./infrastructure/development/web.ps1 -Mode demo` from the repository root. For an isolated local staging API use `./infrastructure/development/web.ps1 -Mode staging -ApiProxyTarget http://127.0.0.1:8000`. The script starts Vite in `apps/web` and proxies `/api` and `/web` to Laravel. Install with `cd apps/web; npm ci`; checks are `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `npm run smoke` (requires Chrome and the dev server). `npm run smoke:staging` requires a dedicated test account in `STAGING_SMOKE_EMAIL` and `STAGING_SMOKE_PASSWORD`.

The React demo uses built-in synthetic content and never calls Laravel. React staging uses Laravel's HttpOnly browser session and CSRF header; a session can survive refresh. The Flutter Web runner remains available for reference via `./infrastructure/development/flutter-web-reference.ps1` on port 3001. Do not put secrets in `VITE_*` or commit real `.env` files.
